# Security

Officebot is a local single-user prototype, not an authenticated internet-facing service. Keep it on loopback and protect the machine, local database, and credentials. Optional OpenAI and Discord connections transmit data to their respective services.

Do not put secrets, private data, or exploit details in public issues. If GitHub private vulnerability reporting is enabled for the repository, use its private reporting feature. Otherwise, avoid submitting sensitive details publicly and wait for the maintainers to provide a private reporting channel.
